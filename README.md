# Flow

Flow is a personal task management app designed to help you organize your day. Keep tasks in dedicated lists, focus on what matters, and track your progress through a simple mobile interface.

**Status: In development.** The features below describe the app's intended experience.

## Main features

- **Create and complete tasks:** Add tasks from the main screen and check them off as you go.
- **Due dates and reminders:** Set deadlines and reminders for each task.
- **Custom lists:** Organize tasks into lists such as Work, Personal, and Groceries.
- **Drag-and-drop ordering:** Reorder tasks to reflect your priorities.
- **Completed view:** See all your finished tasks in one place.
